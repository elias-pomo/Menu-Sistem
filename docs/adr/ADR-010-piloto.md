# ADR-010: Local piloto sin setup, con abono simbólico

- Estado: aceptada
- Fecha: 22/10/2026
- Decisión del plan: D10 (sección 26 de [PLAN.md](../PLAN.md)), opción A

## Decisión

El primer local no paga setup y paga un abono simbólico a cambio de feedback y permiso para mostrar el caso. Se deja por escrito quién es dueño del código y de los datos.

## Consecuencias

Menos presión el primer día real; sin ingreso inicial.
